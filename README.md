
# Group Programming Project: Dancing Man

### Hangman spinoff:
1. Randomly generate a word
2. Every time a player makes a mistake, instead of adding a limb, we add a man to the dance floor.
3. The player loses when they go over the dancing man limit.
4. Have appropriate visual interface including the dancing men, dance floor, generated word, and keyboard.

### Who might use it?
Anyone looking for an easy game to play.

### Input and Output
1. Input: keyboard
2. Output: letters appearing in hangman; adding a dancing man

### Smallest Working Version
1. Randomly generate words
2. Dancing man should be animated
3. Track letters you've tried
4. End game appropriately

### What needs to be researched?
1. Animating the dancing man
2. How to randomly generate words
3. How to know when you've reached the limit (of words)
